Returns & Refunds

Please read this before requesting a return

Return Window

You have 48 hours from the time your order is marked as delivered to request a return.

What We Accept Returns For

  • Item is significantly different from the listing description or photos
  • Item arrived damaged or defective
  • Wrong item was received

What We Do Not Accept Returns For

  • Change of mind after purchase
  • Sizing issues, please check the size guide carefully before ordering
  • Items showing signs of wear
  • Returns requested after the 48-hour window has closed

How to Request a Return

  • Message us on WhatsApp with your order number
  • Describe the issue and attach clear photos
  • We will review your request and respond with next steps
Questions about a return? Contact us on WhatsApp before your return window closes.
